# FoodHub-Data-Analysis
Exploratory Data Analysis of food delivery orders using Python, Pandas, NumPy, Matplotlib and Seaborn.

## Project Overview
This project was completed as part of the Great Learning Python Foundations program.

The objective is to analyze food delivery order data from FoodHub, an online food aggregator, to understand restaurant demand, customer ordering behavior, cuisine preferences, and delivery performance.

## Dataset Information
- Total Records: 1,898
- Total Columns: 9

### Dataset Columns
- order_id
- customer_id
- restaurant_name
- cuisine_type
- cost_of_the_order
- day_of_the_week
- rating
- food_preparation_time
- delivery_time

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Activities
1. Data inspection and understanding
2. Data quality and missing-value checks
3. Descriptive statistical analysis
4. Univariate and multivariate exploratory data analysis
5. Customer and restaurant analysis
6. Cuisine and order analysis
7. Data visualization
8. Business observations and recommendations

## Key Observations
- Shake Shack was identified as the most popular restaurant.
- American cuisine received the highest number of orders.
- Weekend orders were higher than weekday orders.
- Food preparation and delivery times were analyzed.
- Customer ordering patterns and restaurant performance were explored.
